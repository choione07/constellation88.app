# Privacy Policy version 1.0 for the iOS app Constellation88

The app Constellation88 does not collect any user data of any kind. The app does not require an access of the internet as well.

For the calculation of the rise and set time of the moon, the app asks for the user's location. Yet, it is not required, and data are not collected in any kind.

Source code is opened publicly at: https://github.com/choione07/constellation88.app#
